# Mon projet CELIA — prototype d'appli client

Prototype cliquable d'une application mobile pour les futurs clients d'un constructeur de maisons sur mesure : préparer son projet (terrain, budget, maison), s'inspirer, photographier une pièce pour recevoir des idées d'agencement et de déco, puis réserver un premier rendez-vous avec un carnet de projet prérempli.

Concept de design par Estelle Lavenac. Prototype non officiel : les réservations, rappels et propositions d'agencement sont simulés.

Ouvrir `index.html` dans un navigateur (vue téléphone sur ordinateur, plein écran sur mobile).
